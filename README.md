# Consulting Club

**The Case Practice Network — powered by CASECOMMON**

Consulting Club is a structured practice network for consulting candidates.

Core loop:

**Practice → Measure → Match → Improve → Repeat**

CASECOMMON remains the underlying case-practice engine: case rooms, attempt history, competency scoring and partner matching.

## Product focus
- Case Library
- Solo Practice
- Partner Matching
- Interviewer Mode
- Performance Analytics
- University identity
- Shareable progress cards

The product is intentionally not a generic course site, job board, or AI-chatbot wrapper.
